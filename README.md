## Fitur Aplikasi

- Menampilkan profil mahasiswa.
- Menampilkan foto profil.
- Menampilkan informasi identitas dan kontak.
- Mengedit data profil.
- Validasi input nama, email, dan nomor HP.
- Menampilkan halaman About Me.
- Menampilkan daftar keterampilan dan riwayat pendidikan.
- Bottom Navigation untuk berpindah halaman.
- Light Mode dan Dark Mode.

## Teknologi

- Flutter
- Dart
- Material Design

## Cara Menjalankan Aplikasi

1. Clone repository:

   ```bash
   git clone https://github.com/bila200306/soal1-live-coding.git
   ```

2. Masuk ke folder project:

   ```bash
   cd soal1-live-coding/soal2_profil_app
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Jalankan aplikasi:

   ```bash
   flutter run
   ```
